# Zoho CRM Extensions
- **WorkDrive for Zoho CRM**: Manage Zoho WorkDrive files directly inside CRM records. Attach, view, and sync documents without leaving CRM.
- **SharePoint for Zoho CRM**: Attach, view, and sync SharePoint documents in CRM. Ideal for Microsoft 365 teams.
- **Google Drive for Zoho CRM**: Seamless Google Drive file management within CRM. Link folders to contacts, deals, and accounts.
- **OneDrive for Zoho CRM**: Access Microsoft OneDrive files from CRM modules. Perfect for teams using Microsoft cloud storage.
- **Dropbox for Zoho CRM**: Link Dropbox folders to CRM contacts, deals, and accounts.
- **Google Address Toolkit**: Address autocomplete, validation, and geocoding in CRM forms. Uses Google Maps API for accurate addresses.
- **Easy Email for Zoho CRM**: Simplify email tracking, templates, and logging in CRM. Streamline communication workflows.
